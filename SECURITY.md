# Security Policy

## Supported Versions

The following versions of `code-context-mcp` are currently supported with security updates:

| Version | Supported |
| ------- | --------- |
| 1.2.x | :white_check_mark: |
| < 1.2.0 | :x: |

## Reporting a Vulnerability

Security issues should be reported directly and confidentially to the **NexusVibe AI Tech Security Team**.

* **Email:** security@nexusvibe.ai
* **Response Time:** We acknowledge receipt within 24 hours and aim to provide a resolution or patch within 7 business days.

Please do not report security vulnerabilities through public GitHub issues.

## Privacy & Security Disclosures

* **Local-Only Processing:** `code-context-mcp` operates purely locally on your machine.
* **Zero Telemetry:** The AST parser and codebase analysis tools do not transmit any codebase content, metrics, or telemetry to external servers or third-party APIs.
